YOLO Quantization Framework

  • Nov 2025
  • Advanced

In plain words: AI models that spot objects in images are usually too big for small, low-power chips. I shrank one so it can run on that kind of hardware while keeping its accuracy almost the same.

A five-stage Python framework for FPGA-aware YOLO quantization and fixed-point hardware simulation, with less than 0.5% degradation compared with the floating-point baseline.

  • Python
  • Computer vision
  • FPGA

Highlights

  • Built a five-stage Python pipeline covering FPGA-aware quantization of a YOLO object detector.
  • Simulated fixed-point hardware arithmetic to check accuracy before committing to an FPGA design.
  • Kept degradation below 0.5% across the reported detection metrics compared with the floating-point baseline.

Gesture-Controlled IoT System

  • Jan 2026
  • Intermediate

In plain words: a small board with a motion sensor recognizes hand gestures using a tiny AI model, then sends a wireless message that controls another device.

A gesture control system using ESP32 microcontrollers, IMU sensing, spectral feature extraction, and MQTT to trigger remote actuator commands.

  • ESP32
  • TinyML
  • MQTT

Highlights

  • ESP32 microcontrollers read hand motion from an IMU sensor.
  • Spectral feature extraction turns raw motion into features a TinyML model can classify on the device.
  • Recognized gestures travel over MQTT to trigger commands on a remote actuator.
